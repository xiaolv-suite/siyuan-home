## 一、本次发版核心功能与特性矩阵

### 1. CAND-24：家庭群通知一键复制（`src/core/reminders-view-model.ts`）
- **功能目标**：将到期提醒、待办事务以最符合家庭社交沟通习惯的方式快速分发至微信群、企业微信或飞书。
- **实现细节**：
  - 在卡片操作下拉菜单中增加「复制家庭群通知」动作；
  - 输出格式化图文模板：
    ```text
    📢【家庭提醒 · 模块】
    📌 事项：事项标题
    📅 截止：2026-11-15（还剩 14 天 / 今日到期 / 已逾期 N 天）
    👤 责任人：成员称谓
    📝 备注：补充说明
    💡 来自小驴管家智能提醒
    ```
  - 责任人缺省时自适应回退为“全家”，无备注时紧凑收起，拷贝成功后弹出即时气泡回执。

### 2. CAND-25：原生日历视图离线 RFC 5545 ICS 导出（`src/panels/screens/calendar.svelte`、`src/core/ics.ts`）
- **功能目标**：无需接入任何云端或网络日历同步协议，直接离线导出当前月/周的日程为标准日历文件，供手机原生系统日历（iOS / Android）或 Outlook 批量导入订阅。
- **实现细节**：
  - 在提醒「日历」视图顶栏左侧设置高对比度「导出手机日历 (.ics)」快捷按钮；
  - 基于纯本地极简算法构建标准 `VCALENDAR` 与 `VEVENT`，严格遵守 RFC 5545 协议规范（包括 75 字节长度折叠行、`\r\n` CRLF 换行符与转义处理）；
  - 导出文件名自适应携带当前月份或周段标签（如 `lvhome-schedule-2026-11.ics`）。

### 3. CAND-26：全景聚光灯标签与高优紧急度过滤（`src/core/spotlight.ts`、`src/core/spotlight-dialog.ts`）
- **功能目标**：为重度家庭生活条目检索提供媲美 Linear / Raycast 的高级组合过滤语法。
- **实现细节**：
  - 解析器 `parseSpotlightQuery` 自动识别并提取 `#标签名`（如 `#证件`、`#日常`、`#资产`）以及 `!紧急` / `!urgent` / `!overdue` / `!高优` 条件；
  - 标签过滤支持模块中文别名匹配、所属分类名称匹配及用户自定义便签 `#tag` 匹配；
  - 紧急度过滤精确筛选处于已逾期（`daysLeft < 0`）或临期高危态（`daysLeft <= 7` 或带有 `urgent` 标记）的条目；
  - 纯前端动态响应，无缝叠加全字段拼音模糊匹配，状态条实时重算匹配数量。

### 4. CAND-27：台账表头列宽拖拽自适应与持久化记忆（`src/panels/screens/ledger-table.svelte`）
- **功能目标**：解决不同屏幕与模块下字段长短不一导致的换行或截断问题，提供原生桌面级列宽自适应能力。
- **实现细节**：
  - 表头 `<th>` 挂载原生拖拽句柄 `.lv-col-resizer`，指针拖拽时实时更新列宽（`min-width: 50px` 保护，杜绝列塌陷）；
  - 拖拽过程添加 `lv-col-resizing` 全局状态类防止文本选区干扰与光标撕裂；
  - 双击拖拽句柄瞬间恢复自适应宽度；
  - 鼠标释放时增量写回 `settings.ledgerColumnWidths[modKey]` 并触发轻量化设置持久化，跨模块切换与整页刷新后列宽记忆永久存活。

## 二、小驴全家族插件生态联邦联动（Epoch 6 架构）

本轮深入调研 `D:\思源插件\` 本地兄弟插件（打卡、人脉、拾遗、雷切）的实际代码与公开 Bridge 协议，完成零摩擦生态联邦集成：

| 联动插件 | 联动场景与技术调用 | 降级与安全保障 |
|---|---|---|
| **小驴打卡 (`siyuan-checkin`)** | 快捷体征快录（血压/血糖/体重/体温）与家务打卡时，调用 `logCheckinEventSafely` 自动向打卡插件同步上报连续打卡习惯，并附带外部引用条目 `home:<module>:<rowId>:<date>` | 宿主无打卡插件时静默忽略，微任务执行零阻塞管家本地保存 |
| **小驴人脉 (`siyuan-contacts`)** | 台账详情抽屉新增「沉淀为人脉互动」按钮，随礼礼金、家庭成员就诊、合同签署等关键事实可一键沉淀进小驴人脉专属联系人时间线；成员编辑页提供「打开人脉文档」直达链接 | 采用 `getContactsBridge` 安全探测，未安装或未绑定时弹出人脉选择器或温和提示，零报错 |
| **小驴拾遗 (`siyuan-glean`)** | 台账详情抽屉新增「推入拾遗渐进阅读」，对于动辄数万字的大段保单条款、租赁合同与家电说明书，一键推入拾遗长文阅读切片流每日渐进消化 | 未安装时自动提取条款切片标题并一键写入系统剪贴板，平滑回退 |
| **小驴雷切 (`siyuan-speed-switch`)** | 在雷切工作台注册家庭管家到期摘要概览组件，并在雷切快捷动作池中注册 `lvhome.open-capture` 快捷动作 | 采用动态能力探测与超时熔断，完全解耦加载时序 |
