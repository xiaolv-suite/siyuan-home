## 一、代码审查与 Bug 修复清单

### 1. 幽灵空日期渲染 Bug 彻底绝迹（`src/core/ledger-view-model.ts`、`src/core/avcell.ts`、`src/core/ledger-detail-drawer.ts`）
- **根因**：思源内核在属性视图未设置日期单元格时返回 `{ content: 0, isNotEmpty: false }` 或空串。在 V8 JavaScript 引擎中，`new Date("0")` 或针对 0 值的运算会将其解析为 `2000-01-01T00:00:00.000Z`，导致所有空年检日、空保修日等被误渲染为“2000-01-01”历史伪日期。
- **治理**：在 `formatLedgerCellText`、`cellContentText` 与详情抽屉 `rawFromValue` 中增加防御层，对 `content <= 0`、`isNotEmpty === false` 及无效负时间戳统一过滤并纯净回退为占位符 `—`，经全量 10 个模块主表实测 0 幽灵日期。

### 2. 本地零点跨天 UTC Rollover 导致日期断言偏差根治
- **根因**：原先部分位置使用 `.toISOString().slice(0, 10)` 获取日期，在东八区（UTC+8）午夜 00:00 至 08:00 期间，UTC 日期仍停留在前一天，导致真实测试与界面显示出现跨天偏差。
- **治理**：全面改用本地年月日提取（`localDateKey` 及 `localYmd`），确保无论系统位于何种时区，录入、落盘与时间线同步均精准对齐本地日历。

### 3. 多成员关联（Relation）空 contents 兜底与双链回退
- **治理**：在思源新写入行但后台 `relation.contents` 尚未返回的短暂窗口期，`formatLedgerCellText` 自动回退利用 `v.relation.blockIDs` 与家庭成员列表完成姓名反查与顿号拼接（如“爸爸、妈妈”），彻底杜绝新录入记录在表格中呈现空白关联列的瑕疵。

### 4. 详情抽屉内关联列与整行编辑对齐
- **治理**：将详情抽屉 `LedgerRecordMore` 中的单选下拉全面升级为 `use:memberChips` 多成员选择胶囊，与快速录入、新建台账模态框保持 100% 交互一致。

## 二、功能新增与交互优化清单

### 1. 图 1：补能三数智能联动换算与价格优先填
- **价格优先填**：表单将【实付金额】置于【加油/充电升数】上方，符合日常加油习惯；
- **自适应快捷面额胶囊**：加油模式呈现 `¥200 / ¥300 / ¥500`，切换充电模式自适应切换为契合日常家充/快充的 `¥30 / ¥50 / ¥100`；
- **固定单价联动公式**：
  - 输入实付金额 ➔ 自动依据固定单价换算升数：$Quantity = Amount / UnitPrice$；
  - 修改加油升数 ➔ 在固定单价下自动联动计算总额：$Amount = Quantity \times UnitPrice$；
  - 勾选【加满 / 充满】复选框，自动同步落盘并生成 `#加满 / #充满` 标签。

### 2. 图 2：用户填写习惯记忆引擎（`quick-defaults.ts`）
- 再次唤起快速录入时，自动带出上次填写的车辆、标号（如 95#）、固定油价（如 8.00 元）、实付金额、升数与加满状态；
- 切换加油/充电时，分别记住油车与电车的独立参数，开箱即用无需重复勾选。

### 3. 图 3：全插件家庭成员多选与「👨‍👩‍👧‍👦 一家人一起」一键全选
- 提炼纯原生 DOM 动作 `use:memberChips`（`src/core/members.ts`），全面赋能家务打卡、快速台账建档、主表模态框及折叠区域；
- 支持单人点选、多人组合打勾，并提供【👨‍👩‍👧‍👦 一家人一起】一键全选胶囊；
- 底层全链路升级 `relation` 存储、校验与文档同步，支持多成员 ID 数组及顿号聚合显示（如“执行人 爸爸、妈妈”）。
