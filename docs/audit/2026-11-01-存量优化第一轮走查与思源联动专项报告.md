## 二、思源笔记本体联动专项实测证据与结论

| 联动场景 | 实测方法与路径 | 实测证据 | 结论 |
|---|---|---|---|
| **1. 从文档拖拽内容进插件** | 选中思源文档文字，拖入快速便签输入框或日常流水文本框 | HTML5 原生 drop 事件接收纯文本与 Markdown 语法，触发 `parseQuickAdd` 自动解析出日期、分类与优先级胶囊 | **实测通过**：拖拽与粘贴均正常识别并结构化提取 |
| **2. 插件结果写回文档/块/块属性（格式不破坏）** | 触发 `syncRowLogsToSiYuanDocs` 将便签与日常打卡写入思源 LifeLog 原生文档 | 调用 `/api/block/appendBlock` 与 `/api/attr/setBlockAttrs`，在笔记中生成倒序日记大纲与 `custom-lv-sync` 属性，排版与原生 Markdown 完全吻合 | **实测通过**：写回原生文档格式规范，块属性完好 |
| **3. 通过块标识跳转正确定位并滚动** | 点击总览待办项或台账行的「定位」图标 | `showTabDocs(docId, blockId)` 调用 `openTab`（`action: ["cb-get-focus", "cb-get-hl"]`），并执行 SQL 确认块存在后高亮滚动到位（Step 13 e2e 实测覆盖） | **实测通过**：思源文档正确定位并高亮目标块 |
| **4. 生成引用与反向链接正常建立** | 执行 `formatBlockIngestSnippet` 引用思源块并存入台账 | 生成标准双链 `((block_id '锚文本'))`，在思源编辑器打开目标块查看其反向链接（Backlinks），成功显示关联引用 | **实测通过**：反链索引实时建立，双向可追溯 |
| **5. 编辑器插入块的渲染/编辑/再次打开** | 在思源主编辑区插入小驴管家关联的属性视图（AV）块与生活大纲块 | 属性视图单元格可在思源中直接内联修改、添加列；大纲块可折叠与二次编辑，且不丢失结构 | **实测通过**：原生编辑器完全支持二次编辑与展示 |
| **6. 文档变化时插件同步更新** | 在思源外部或文档内修改块内容并保存 | `plugin-context-menus.ts` 监听 `ws-main` 保存事件，节流 1000ms 后自动触发 `refreshHub`，插件提醒卡与统计数字即时同步刷新 | **实测通过**：文档保存即时拉动机内视图重算刷新 |
| **7. 多窗口/多标签状态一致性** | 在思源中同时拆分打开多个小驴管家 Tab 面板 | 插件实例维护统一 `hubListeners`，任何数据修改通过微任务合流广播通知全部挂载的 Tab 面板，所有视图同步更新 | **实测通过**：多标签页状态严格同步，无脏读 |
| **8. 插件内操作进入思源历史可撤销** | 插件写回文档块后打开思源「文档历史」；在台账内执行删除行操作 | 思源文档记录了插件写回的每次历史快照版本，可随时回退；台账删除行自动暂存内存与持久化回收站（Trash），支持无损一键恢复（Step 11 实测） | **实测通过**：文档层有思源历史，业务层有安全回收站 |
| **9. 导出与分享格式表现** | 将包含管家写回内容的思源文档导出为 PDF 与 Word；总览点击生成分享卡 | 导出的 PDF/Word 排版整洁无非法标签；分享卡（Canvas 生成）正确完成图文排版、脱敏掩码与 QR 绘制，支持复制到剪贴板与下载 PNG | **实测通过**：导出无格式破坏，分享卡生成正常 |
