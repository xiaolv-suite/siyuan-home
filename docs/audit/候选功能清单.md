# 小驴管家（Lv Home）· 候选功能清单

> **说明**：本清单用于存放走查与审查过程中发现的“本可以做得更好、或缺少某个能让体验更完整的点”。
> **铁律**：严禁未经确认直接实现！每条必须清晰阐述：是什么、解决什么问题、影响哪类用户、预估成本、与现有功能是否重叠。
> **流转机制**：用户审阅后决定是否加；决定加的转入《存量优化待办池》，不加的标注原因后就地留存关闭，避免反复讨论同一件事。
