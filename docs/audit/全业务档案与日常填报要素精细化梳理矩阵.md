# 小驴管家（Lv Home）· 全业务档案与日常填报要素精细化梳理矩阵

> **梳理目标**：围绕小驴管家 31 个核心台账模块与 5 大日常高频流水，从 **【重要性】、【未来取用查询的便利性】、【内容重要性与全面性】、【记录便利性】、【直接点选便利性】、【历史数据复用性】、【思源笔记联动性】、【未来数据分析标准化】** 8 大维度展开精细化梳理。

---

## 一、 顶层 8 维设计哲学与填报分层模型

为了既避免“为了规范把用户累死在录入表单上”，又避免“随意记录导致未来无法结构化查询分析”，小驴管家将所有填报要素划分为 **四层漏斗模型**：

```
┌────────────────────────────────────────────────────────┐
│  L1. 极简主键层 (Required) : 名称/标题 + 核心数值/日期  │ ← 2 秒极速录入，允许粗粒度（如“日用品 ¥85”）
├────────────────────────────────────────────────────────┤
│  L2. 索引分类层 (Indexed)  : 成员归属 + 业务分类 + 状态  │ ← 1 键点选，支撑全局多维筛选、权限与预算统计
├────────────────────────────────────────────────────────┤
│  L3. 周期与提醒层 (Lifecycle): 到期日 + 提前提醒 + 循环  │ ← 自动挂载提醒中枢与日历排期，Things 3 拖拽
├────────────────────────────────────────────────────────┤
│  L4. 深度扩展层 (Deep Meta): 凭证图片 + 详情大纲 + 块双链│ ← 留在思源原生文档与抽屉中按需渐进补充
└────────────────────────────────────────────────────────┘
```

| **3. 家务打卡与成长** | ① 家务项目<br>② 执行成员 (支持多成员/全家共同)<br>③ 奖励积分/零花钱<br>④ 简短备注 | **高**<br>亲子互动、习惯培养与零花钱结算 | · **高频家务前置**：下拉框下方直出前 5 项高频胶囊（[洗碗] [倒垃圾]）一键点选<br>· 成员头像气泡支持一键多选（“全家一起”） | 自动带入预设积分倍率与上次成员组合 | 自动触发家庭账本积分增加并落地 LifeLog，可一键兑换零花钱台账 | 标准化按月统计家庭成员劳动贡献率与积分兑现履约率 |
| **4. 待买清单与日常采购** | ① 品名 (粗/细粒度)<br>② 预估/实付总额<br>③ 消费分类 (日用/食材/外卖等)<br>④ 数量 (粗粒度免填，默认1) | **极高**<br>日常开支最频繁入口 | · **粗粒度总额开销**：提供 `[日用品]`、`[买菜食材]`、`[超市采购]` 等大类胶囊，点击品名与分类秒填，光标直达金额<br>· **常用耗材速选**：`[鸡蛋]`、`[牛奶]`、`[抽纸]` 一键直达 | 自动记住高频品名与常用归类 | 购买完成后一键勾选归档，或升级为家庭物资囤货资产 | 粗粒度总价可直接汇入月度开支分析，避免繁杂细账导致弃记 |

## 四、 核心优化结论与下一步演进指引

1. **粗细粒度兼顾的普适法则**：
   - 凡是**日常高频发生的事情**（加油、买菜、小额支出、家务），**必须优先支持粗粒度总额与预设一键点选**，绝不把用户卡在件数与分类细账上；
   - 凡是**低频但后果严重的档案**（保险、合同、证件、病历），**必须保障要素全面性与思源块双链深度挂载**，确保 3 年、5 年后查询时信息完整、凭证可溯。
2. **零外链离线手册的战略价值**：
   - 本地单文件 HTML 全景手册（CAND-11）将所有分散档案整合为无依赖静态文件，是对思源数据安全的物理灾备级兜底，极大满足了换机、断网或家庭交接时的查阅便利性。
3. **数据标准化促进智能分析**：
   - 通过将数值与单位彻底解耦、严格日期 ISO 化、枚举字典收拢，底栏动态汇总（CAND-16）与折旧/能耗趋势得以零延迟、高精度秒级呈现。
